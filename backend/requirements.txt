# VoxShield backend dependencies
#
# IMPORTANT - PyTorch is NOT installed from here.
#
# On Windows the PyPI torch wheels are CPU-only, so `pip install torch` gives
# you a build that cannot see the GPU at all. Install the CUDA build first,
# from PyTorch's own index, then install this file:
#
#   pip install --index-url https://download.pytorch.org/whl/cu130 \
#       torch==2.14.0+cu130 torchaudio==2.11.0+cu130
#   pip install -r backend/requirements.txt
#
# cu130 matches the CUDA 13.1 driver on this machine. For an older driver use
# cu128. Verify afterwards:
#
#   python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# ---------------------------------------------------------------------------
